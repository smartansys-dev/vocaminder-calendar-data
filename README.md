# VocaMinder calendar schema V2
Development infrastructure only. No verified Vakya yearly dataset is included. The template intentionally fails production validation. Keep the existing V1 tamil_calendar.json in place for the current Android client. Publish yearly files only after independent source verification and redistribution permission. Month end dates are inclusive. Unknown optional values are null; empty arrays mean confirmed absence. All timestamps use IST. Panchangam transitions are ordered arrays; festival and lunar-event semantics must be documented by the eventual source. Index entries must match validated yearly files. Increment dataVersion for corrections. Run `pip install -r requirements.txt` then `python scripts/validate_calendar.py`. Validation checks structure and date continuity, not astronomical correctness. An empty index is valid scaffolding, not usable calendar coverage. No automated generation is enabled until a source is established.
