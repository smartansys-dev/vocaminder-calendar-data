# Experimental Vakya engine — Step 3A
Upstream: https://github.com/AKBKGK/sankalpam-generator, uploaded commit fd1f66c0e7cc5b03936c525d81f1105608c7ba5d. Extracted Panchanga script from index.html; retained MIT notice in engine/LICENSE. Adapter reproduces upstream Vakya sunset cutoff. No network or npm dependencies for monthStarts. Unused Drik functions are retained but not supported by this adapter.
Run `node tests/test_vakya_engine.js` from repository root (Node 22 tested). The eight regression dates are from earlier project discussion, not independently verified in this step. Range 2025–2051 is experimental, not an accuracy guarantee. Upstream uses a traditional fixed-latitude day-length model, not exact Chennai sunset; lunar calibration is fitted to 2026–27 and upstream recommends yearly rechecks. Do not publish these results as verified calendar data. No Android or calendar index changes.
